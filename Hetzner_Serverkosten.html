Empfohlene Vorgehensweise

Start mit kleinstem Server

Wir starten zunächst mit dem Hetzner CX23 Server (4,49 EUR/Monat inkl. MwSt.).


Vorteile:

  • Sehr niedrige Einstiegskosten
  • Ausreichend für Prototyp und erste Tests
  • Geringes finanzielles Risiko
  • Jederzeit ohne Datenverlust skalierbar

Kostenanpassung bei Wachstum

Die Kosten können später je nach Nutzung steigen:

  • Bei mehr Benutzern: Upgrade auf CX33 (ca. +2,50 EUR/Monat)
  • Bei umfangreicheren Daten: Upgrade auf CX43 (ca. +8,00 EUR/Monat)
  • Bei erhöhtem Speicherbedarf: Zusätzlicher Storage (ca. 5-10 EUR/Monat pro 100 GB)

Der Server kann jederzeit ohne Datenverlust vergrößert werden. Die Skalierung erfolgt bedarfsgerecht.

VPN-Anbindung (Vorhanden)

Bestehendes VPN wird genutzt

Das Kunsthaus verfügt bereits über ein VPN-System.


Vorteile:

  • Keine zusätzlichen VPN-Kosten
  • Verschlüsselte Verbindung zum Server
  • Schutz vor unbefugtem Zugriff
  • Sichere Verbindung auch von unterwegs
  • Professioneller Standard für Unternehmensdaten

Aufgabe für IT-Dienstleister Ruben

Bitte Ruben (IT-Dienstleister) kontaktieren für folgende Konfigurationen:


1. VPN-Tunnel zum Hetzner Server einrichten

  • Sichere VPN-Verbindung zwischen Kunsthaus-Netzwerk und Hetzner Server konfigurieren
  • Authentifizierung und Verschlüsselung einrichten
  • Firewall-Regeln für sicheren Zugriff festlegen

2. Netzwerk im Kunsthaus konfigurieren

  • Interne Netzwerkanbindung für Mitarbeiter-Zugriff einrichten
  • Routing zum Server über VPN-Tunnel konfigurieren
  • Zugriffsberechtigungen für autorisierte Mitarbeiter festlegen
  • DNS-Konfiguration für einfachen Zugriff (z.B. projektsoftware.kunsthaus.local)

Zugriffsbeschränkungen

Zugriff nur über Kunsthaus-Netzwerk

Der Zugriff auf den Server ist standardmäßig nur über das Kunsthaus-Netzwerk möglich.


Sicherheitsdetails:

  • Zugriff nur über das VPN-gesicherte Kunsthaus-Netzwerk
  • Nur Geräte im Kunsthaus-Netzwerk können auf den Server zugreifen
  • Externe Zugriffe sind ohne VPN-Verbindung nicht möglich
  • Dies erhöht die Sicherheit erheblich

Für Zugriff von außerhalb des Kunsthauses:

  1. VPN-Verbindung zum Kunsthaus-Netzwerk aufbauen
  2. Erst dann ist der Zugriff auf den Server möglich
  3. VPN-Zugänge werden durch IT-Dienstleister Ruben verwaltet
