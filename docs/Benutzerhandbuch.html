Dashboard

Nach der Anmeldung sehen Sie das Dashboard mit:

Projektübersicht

Aktuelle Statistiken

Direkt zu Rechnungen und Lieferanten

Rechnungen

Rechnungsübersicht öffnen

Klicken Sie links auf "EK-Rechnungen". Sie sehen alle Rechnungen die einem Projekt zugeordnet sind.

Rechnungen filtern

Nutzen Sie die Filter oben:

Filter Beschreibung
Status Offen Kontrolliert Bezahlt
Projekt Nur Rechnungen eines bestimmten Projekts
Lieferant Nur Rechnungen eines Lieferanten
Abgabestelle Gemeinde, Region, Provinz

Rechnung bearbeiten

1
Details öffnen Klicken Sie auf "Details" bei einer Rechnung
2
Daten ändern Sie können folgendes bearbeiten:
  • Kontrolliert - Checkbox + Datum (automatisch heute, manuell änderbar)
  • Bezahlt - Checkbox + Datum (automatisch heute, manuell änderbar)
  • Kostentyp - Personal, Material, etc. + Datum der Zuordnung
  • Abgabestelle - Gemeinde, Region, Provinz + Datum der Zuordnung
  • Notizen - Freies Textfeld
Automatische Datums-Erfassung: Bei jeder Statusänderung wird automatisch das heutige Datum gesetzt. Sie können das Datum aber auch manuell ändern, falls z.B. eine Rechnung rückwirkend als bezahlt markiert werden soll.

Mehrere Rechnungen bearbeiten

1
Auswählen Setzen Sie Häkchen bei den gewünschten Rechnungen (oder alle auswählen im Tabellenkopf)
2
Aktion wählen Eine blaue Leiste erscheint mit folgenden Optionen:
Als kontrolliert Als bezahlt Gemeinde Region Provinz

PDF-Rechnung ansehen

Klicken Sie auf das PDF-Symbol in der Zeile. Die Rechnung öffnet sich in einem neuen Tab.

Hinweis: Wenn kein PDF-Symbol erscheint, wurde die Rechnungsdatei noch nicht abgelegt.

Lieferanten

Lieferantenliste öffnen

Klicken Sie links auf "Lieferanten". Sie sehen alle Lieferanten mit Partita IVA.

Lieferantenname bearbeiten

Falls ein Lieferantenname fehlt oder falsch ist:

  1. Klicken Sie auf das Stift-Symbol neben dem Namen
  2. Geben Sie den korrekten Namen ein
  3. Klicken Sie auf OK
Der Name wird gespeichert und erscheint bei allen Rechnungen dieses Lieferanten.

Rechnungen eines Lieferanten anzeigen

Klicken Sie auf "Rechnungen" bei einem Lieferanten. Sie werden zur gefilterten Rechnungsansicht weitergeleitet.

Projekte

Projektübersicht

Klicken Sie links auf "Projekte". Sie sehen alle Projekte mit Gesamtkosten, Anzahl Rechnungen und Status.

Daten exportieren

CSV-Export

1
Gehen Sie zu "EK-Rechnungen"
2
Filtern Sie bei Bedarf (Projekt, Status, etc.)
3
Klicken Sie auf CSV Export
Die CSV-Datei enthält alle angezeigten Rechnungen mit Status-Informationen und kann in Excel geöffnet werden.

Archiv (vergangene Jahre)

Falls Jahresarchive vorhanden sind:

  1. Gehen Sie zu "EK-Rechnungen"
  2. Oben erscheint ein Dropdown mit Jahren
  3. Wählen Sie das gewünschte Jahr
Hinweis: Archiv-Daten können nur angesehen, nicht bearbeitet werden.

Tipps & Hinweise

Browser-Empfehlung

  • Google Chrome (empfohlen)
  • Microsoft Edge
  • Firefox

Daten aktualisieren

Wenn neue Daten importiert wurden: Klicken Sie auf "Aktualisieren" oder drücken Sie F5

Status-Daten

Ihre Änderungen werden automatisch gespeichert.

Wichtig:
  • Verwenden Sie immer denselben Browser
  • Löschen Sie keine Browser-Daten
  • Nutzen Sie kein privates/Inkognito-Fenster

Tastenkürzel

F5 Daten neu laden Strg + F Im Browser suchen Esc Dialog schließen

Häufige Fragen

Warum sehe ich keine Rechnungen?

Möglicherweise wurde noch kein Import durchgeführt oder die Rechnungen haben keine gültige Projekt-ID. Kontaktieren Sie Barbara.

Warum fehlt die PDF-Datei?

Die PDF wurde noch nicht abgelegt oder der Dateiname stimmt nicht. Kontaktieren Sie Barbara.

Meine Änderungen sind weg?

Status-Daten sind browser-spezifisch. Haben Sie den Browser gewechselt oder wurden Browser-Daten gelöscht?

Wie exportiere ich nach Excel?

CSV-Export durchführen → CSV-Datei in Excel öffnen → Bei Bedarf als .xlsx speichern

Abmelden

Klicken Sie unten links auf "Abmelden". Sie werden zur Anmeldeseite weitergeleitet.
