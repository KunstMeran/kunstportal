Warum diese Migration?

Sicherheit

  • PostgreSQL nicht von außen erreichbar
  • Session-Cookies statt JWT im Browser
  • Volle Kontrolle über jeden API-Endpunkt
  • Keine fremden Komponenten (GoTrue, Kong, etc.)

Kosten & Kontrolle

  • ~7€/Monat statt ~25€ bei Supabase Pro
  • EU-Datenresidenz (Hetzner Falkenstein)
  • Unbegrenzte Datenbank-Größe
  • Kein Vendor Lock-in

Architektur

┌─────────────────┐ ┌─────────────────┐ │ Browser │ │ Hetzner VPS │ │ │ HTTPS │ (CX22, 4GB) │ │ app.kunstmer- │◄──────────────────►│ │ │ anoarte.org │ Port 443 │ ┌───────────┐ │ │ │ │ │ Caddy │ │ └─────────────────┘ │ │ (Proxy) │ │ │ └─────┬─────┘ │ │ │ │ │ ▼ │ │ ┌───────────┐ │ │ │ Express │ │ │ │ Port 3000 │ │ │ └─────┬─────┘ │ │ │ │ │ ▼ │ │ ┌───────────┐ │ │ │PostgreSQL │ │ │ │Port 5432 │ │ │ │(localhost)│ │ │ └───────────┘ │ └─────────────────┘
Wichtig: PostgreSQL ist NUR auf localhost (127.0.0.1) erreichbar. Port 5432 ist NIEMALS von außen zugänglich!

Hauptserver (server.js)

const express = require('express');
const session = require('express-session');
const pgSession = require('connect-pg-simple')(session);
const helmet = require('helmet');
const cors = require('cors');
const rateLimit = require('express-rate-limit');
const { pool } = require('./db');

const app = express();

// Sicherheits-Header
app.use(helmet());

// CORS nur für Frontend-Domain
app.use(cors({
    origin: 'https://app.kunstmeranoarte.org',
    credentials: true
}));

// JSON Body Parser
app.use(express.json({ limit: '10mb' }));

// Rate-Limiting: Max 100 Requests pro Minute
app.use(rateLimit({
    windowMs: 60 * 1000,
    max: 100,
    message: 'Zu viele Anfragen, bitte warten.'
}));

// Session mit PostgreSQL-Store
app.use(session({
    store: new pgSession({ pool }),
    secret: process.env.SESSION_SECRET,
    resave: false,
    saveUninitialized: false,
    cookie: {
        secure: true,       // Nur HTTPS
        httpOnly: true,     // Kein JS-Zugriff
        sameSite: 'strict', // Kein CSRF
        maxAge: 8 * 60 * 60 * 1000 // 8 Stunden
    }
}));

// Routes
app.use('/api/auth', require('./routes/auth'));
app.use('/api/projects', require('./routes/projects'));
app.use('/api/bookings', require('./routes/bookings'));
app.use('/api/invoices', require('./routes/invoices'));
app.use('/api/members', require('./routes/members'));
app.use('/api/suppliers', require('./routes/suppliers'));
app.use('/api/funding-sources', require('./routes/funding-sources'));
app.use('/api/workspaces', require('./routes/workspaces'));
app.use('/api/shop', require('./routes/shop'));

// Health Check
app.get('/health', (req, res) => res.json({ status: 'ok' }));

// NUR auf localhost hören!
app.listen(3000, '127.0.0.1', () => {
    console.log('API Server läuft auf localhost:3000');
});

Frontend anpassen

Dauer: ~3-4 Stunden

Neue Datei: js/api-client.js

const ApiClient = {
    baseUrl: 'https://api.kunstmeranoarte.org',

    async request(endpoint, options = {}) {
        const res = await fetch(`${this.baseUrl}${endpoint}`, {
            ...options,
            credentials: 'include', // Session-Cookie senden
            headers: {
                'Content-Type': 'application/json',
                ...options.headers
            }
        });

        if (res.status === 401) {
            window.location.href = 'index.html';
            throw new Error('Nicht autorisiert');
        }

        if (!res.ok) {
            const error = await res.text();
            throw new Error(error);
        }

        return res.json();
    },

    // Auth
    login: (email, password) =>
        ApiClient.request('/api/auth/login', {
            method: 'POST',
            body: JSON.stringify({ email, password })
        }),

    logout: () =>
        ApiClient.request('/api/auth/logout', { method: 'POST' }),

    getMe: () =>
        ApiClient.request('/api/auth/me'),

    // Projects
    getProjects: () => ApiClient.request('/api/projects'),
    getProject: (id) => ApiClient.request(`/api/projects/${id}`),
    createProject: (data) => ApiClient.request('/api/projects', {
        method: 'POST', body: JSON.stringify(data)
    }),
    updateProject: (id, data) => ApiClient.request(`/api/projects/${id}`, {
        method: 'PUT', body: JSON.stringify(data)
    }),
    deleteProject: (id) => ApiClient.request(`/api/projects/${id}`, {
        method: 'DELETE'
    }),

    // ... weitere Methoden analog
};

Caddy Reverse Proxy + SSL

Dauer: ~15 Minuten

Datei: /etc/caddy/Caddyfile

# API Backend
api.kunstmeranoarte.org {
    reverse_proxy localhost:3000

    header {
        Strict-Transport-Security "max-age=31536000; includeSubDomains; preload"
        X-Content-Type-Options "nosniff"
        X-Frame-Options "DENY"
        X-XSS-Protection "1; mode=block"
        Referrer-Policy "strict-origin-when-cross-origin"
    }
}

# Frontend (statische Dateien)
app.kunstmeranoarte.org {
    root * /var/www/kunstmeran
    file_server

    # SPA-Fallback
    try_files {path} /app.html

    header {
        Strict-Transport-Security "max-age=31536000; includeSubDomains; preload"
        X-Content-Type-Options "nosniff"
        X-Frame-Options "SAMEORIGIN"
    }
}
systemctl reload caddy
Caddy holt automatisch Let's Encrypt Zertifikate. Kein manuelles SSL-Setup nötig!

Daten migrieren

Dauer: ~1 Stunde

Von Supabase exportieren

# Supabase Dashboard → Settings → Database → Connection String
pg_dump "postgresql://postgres:PASSWORD@db.xxx.supabase.co:5432/postgres" \
    --schema=public \
    --no-owner \
    --no-acl \
    -F c -f kunstmeran_backup.dump

Auf Hetzner importieren

# Dump auf Server kopieren
scp kunstmeran_backup.dump root@HETZNER_IP:/tmp/

# Auf Server einloggen und importieren
ssh root@HETZNER_IP
pg_restore -U kunstmeran_app -d kunstmeran \
    --clean --if-exists /tmp/kunstmeran_backup.dump

Sicherheits-Checkliste

  • PostgreSQL nur auf 127.0.0.1 (pg_hba.conf prüfen)
  • Hetzner Firewall: Port 5432 ist NICHT offen
  • Session-Secret ist mindestens 64 Zeichen lang
  • HTTPS ist erzwungen (Caddy HSTS-Header)
  • Rate-Limiting ist aktiv (100 req/min)
  • Input-Validation auf allen Endpunkten
  • SQL-Injection-Schutz (Parameterized Queries)
  • CORS nur für Frontend-Domain erlaubt
  • Keine Secrets im Git-Repository (.env in .gitignore)
  • fail2ban für SSH-Brute-Force-Schutz
  • Automatische Backups konfiguriert
